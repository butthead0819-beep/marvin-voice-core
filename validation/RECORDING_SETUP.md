# 聊天室錄音設定（macOS + OBS）

> 目的：錄下語音頻道，交給 `scripts/make_subtitle_video.py` 做成字幕直式短片。
> 2026-09-27 寫。標「待確認」的是還沒在這台 Mac 上實測過的。

## 0. 錄之前一定要做

- 跟頻道裡的人講清楚：**這段會被錄下來，可能剪成短片放上網**。沒答應的人，他的片段不要用。
- OBS 錄的是 Discord 播出的**所有聲音**，不管那個人有沒有在 Marvin 那邊按同意。

## 1. 安裝與權限（一次性）

1. 安裝 OBS（官網 obsproject.com，或 `brew install --cask obs`）。
2. 第一次開 OBS 時，在「系統設定 → 隱私權與安全性」允許 OBS 的**螢幕錄製**（擷取 App 聲音需要）與**麥克風**。

## 2. OBS 設定（一次性）

**來源**
- 「應用程式音訊擷取」→ 選 **Discord**：錄到所有人和 Marvin。
- 第一場（你本人用 Mac 開語音）：再加「音訊輸入擷取」→ 你的麥克風。你的聲音不在 Discord 的輸出裡，不加就錄不到你。
- 小帳號長期錄：**不用加麥克風**。你在手機上講話，會從 Discord 的輸出進來。

**輸出**（設定 → 輸出，切成「進階」）
- 錄影格式：**mkv**。當機或斷電時檔案不會整個壞掉，工具也吃得了。
- 錄影路徑：例如 `~/Movies/Marvin錄音/`。
- 影片：只要聲音，畫面壓到最小。解析度調到 640×360、位元率約 100–200 kbps。
- 音訊位元率：160 kbps。
- **檔名格式保持預設**（`%CCYY-%MM-%DD %hh-%mm-%ss`）。字幕工具靠檔名得知錄音開始時間。

**大小估計**：約 110 MB / 小時。每晚 4 小時約 0.45 GB，一個月約 13 GB（目前可用空間 37 GB，要定期清）。

## 3. 第一場：你本人在 Mac 上

1. Mac 的 Discord 用**你的帳號**進語音頻道。手機不要同時進，同一帳號只能有一個語音連線。
2. **先用 `/marvin_play_control` 把音樂停掉**：這一場沒辦法把馬文和音樂分開，錄到歌就不能用。挑片時 `marvin_audio` 填 `"original"`。
3. OBS 按「開始錄影」→ 聊天 → 「停止錄影」。
4. 錄完先聽前 1 分鐘，確認別人、你、Marvin 的聲音都有錄到。

## 4. 長期：錄音小帳號

1. 開一個新的 Discord 帳號（例如叫「錄音機」），加入主伺服器。Mac 的 Discord 登入它。
2. 進頻道後把小帳號**靜音麥克風**（不要按「拒聽」，拒聽就收不到聲音了）。
3. **在小帳號的 Discord 裡把馬文「本地靜音」**：右鍵馬文 → 使用者音量拉到 0%。這樣 OBS 錄到的只有人聲、沒有歌；馬文的聲音出片時由工具依台詞紀錄重新合成（`marvin_audio` 填 `"resynth"`）。只影響小帳號，其他人照常聽得到。**音樂照常放沒關係。**
4. 每次大家開聊時，小帳號進頻道、OBS 開始錄；散場時小帳號離開、OBS 停止。
   **要手動操作**。不要用程式自動操作 Discord 使用者帳號，那違反 Discord 條款。

**小帳號會被 Marvin 當成一個真人**（程式照現狀，不改）：
- 第一次進來會跳同意通知 → 按「拒絕」。它本來就不講話，按拒絕 Marvin 也不會處理它的任何東西。
- Marvin 會跟它打招呼，把它算進「在場人數」。
- ⚠️ **大家都走了，只要小帳號還在，Marvin 就不會自動離開**，還可能對著空房間丟冷場話題。**散場時記得讓小帳號離開**。

## 5. 錄完之後

挑片與出片流程見 `CLIP_PICKING.md`（跟 Claude Code 說「幫我從 <錄音檔> 找素材」）。以下是只想整段輸出時的舊用法：

```
./venv_simon/bin/python -m scripts.make_subtitle_video prepare "~/Movies/Marvin錄音/2026-09-28 22-10-05.mkv"
（改 .srt）
./venv_simon/bin/python -m scripts.make_subtitle_video render "…mkv" "…srt"
```
- 馬文的台詞要 2026-09-27 14:05 之後錄的才有（`marvin_speech.log` 從那時開始）。
- 用不到的錄音檔要刪掉。這些是朋友們的聲音，屬於個人資料，不要一直留著。

## 待確認
- Mac 的系統音量調到很小或靜音時，OBS 的應用程式音訊擷取是否仍錄得到正常音量。第一場順便試一下。
