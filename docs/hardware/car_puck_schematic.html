💡 懶人福利：一鍵生成 STL 的 OpenSCAD 3D 腳本代碼 (已校準 54mm 磁吸槽)

你甚至不需要會用複雜的 3D 軟體！把以下代碼貼進免費開源的 OpenSCAD，按 F6 算圖 ➔ 匯出 STL，就能 1 秒鐘直接生成發給 JLC3DP 列印的 3D 檔案！ 

// Marvin Car Puck — 雙層板微型 3D 外殼 (OpenSCAD 腳本)
// 正面極簡 Ø42mm，底盤微擴展至 Ø55mm 完美內嵌 54mm MagSafe 環
$fn = 100;

module top_bezel() {
    difference() {
        cylinder(d=42.0, h=6.5); // 前蓋直徑 Ø42mm
        translate([0, 0, -1]) cylinder(d=33.0, h=10); // 螢幕視窗 Ø33mm
        translate([0, 0, 4.9]) cylinder(d=36.0, h=2.0); // 螢幕內沉台
        translate([-11, 11, -1]) cylinder(d=1.5, h=10); // 麥克風孔
        for(a=[0, 120, 240]) rotate([0, 0, a]) translate([19.0, 0, -1]) cylinder(d=2.2, h=10); // M2 螺絲孔
    }
}

module bottom_case() {
    difference() {
        // 純直筒 Ø42.0mm 外殼 (完全不變大，無任何向外擴展)
        cylinder(d=42.0, h=8.0);
        translate([0, 0, 2.0]) cylinder(d=38.6, h=8.0); // 內部容納 Ø38mm PCB
        // 底面 Apple Watch 磁吸充電座凹槽 (Ø28.5mm, 深 1.2mm)
        translate([0, 0, -0.1]) cylinder(d=28.5, h=1.3);
        // 6點鐘正下方 Type-C 凹槽
        translate([-6.0, -22.0, 2.0]) cube([12.0, 10.0, 6.5]);
    }
}

// 平鋪預覽
translate([-25, 0, 0]) top_bezel();
translate([25, 0, 0]) bottom_case();

為什麼需要「ESP32-S3 + ESP32」雙晶片架構？ 💡

許多人第一次做 ESP32 專案會問：「為什麼不能單顆晶片全包？」。以下是 Car Puck 核心設計的物理約束：

  • ESP32-S3 沒有傳統藍牙 (Classic BT)：S3 雖然擁有強大雙核、Vector 向量指令集與 8MB Octal PSRAM（能順跑 24fps 3D 面部旋轉渲染與 MP3 軟解碼），但它只支援 BLE，不支援 A2DP。車載藍牙主機（如 BMW iDrive）與大部分藍牙音箱強制需要 Classic BT A2DP Profile。
  • Classic ESP32 (D0WD) 記憶體與算力吃緊：傳統 ESP32 具備 Classic BT，但若同時維持 WiFi 連線、HTTPS TLS 握手、MP3 串流緩衝與 240px 圓屏高頻刷新，內部 RAM 會嚴重匱乏且頻繁與藍牙 Baseband 搶佔 RF。
  • 雙晶片職責解耦：S3 作為主力大腦（WiFi、解碼、螢幕、語音）；WROOM 專職做為高可靠性的純藍牙音訊 Bridge，兩者以 I2S 數位音訊與 UART 中繼互連，完全無干擾。
客製 PCB 取代杜邦線的四大決定性好處 🚀
1. 徹底消除 40MHz 高頻 SPI 螢幕干擾
杜邦線長度常達 10~20cm，分佈電容極高。GC9A01 以 40MHz 傳輸時容易造成時脈波形畸變破圖。PCB 走線可控制在 3cm 以內且匹配地平面。
2. 零 Jitter 的 I2S 數位音訊無爆音
S3 傳給 WROOM 的 I2S 包含 BCLK、LRCLK、DIN。杜邦線只要稍受車載點火線圈或震動影響就會掉 Frame 產生清脆爆音。
3. 承受車載震動與溫度循環
車載環境夏天暴曬車內可達 60°C~70°C，顛簸路段會使杜邦線端子氧化接觸不良。SMT 表面貼裝具備工業級耐震與可靠度。
4. 極致微型化可塞入圓形中控出風口
杜邦線纏繞體積龐大；客製 PCB 可做成 Ø45mm 圓形板，直接與 1.28 吋 GC9A01 圓屏重疊固定於中控出風口磁吸支架。

如何請 JLCPCB 連元件都「直接焊上去」(PCBA / SMT 流程)？

在 JLCPCB 製作「洗板 + 打件（SMT Assembly）」其實非常自動化。你不需要自己買零件寄過去，JLCPCB 擁有立創商城 (LCSC) 的百萬庫存零件庫，下單時只需上傳設計檔，他們的機械手臂就會自動取料並回流焊接！

1

使用 EasyEDA (嘉立創 EDA) 或 KiCad 繪製原理圖與 PCB

最推薦方式：使用「嘉立創 EDA 專業版」(EasyEDA Pro)。
原因：EasyEDA 直接內建立創商城 (LCSC) 的即時庫存與 3D 模型庫。你在放置 ESP32-S3、Type-C、電阻電容時，直接選取帶有 JLCPCB Part # (Cxxxxxx) 的零件，就能保證 100% 有庫存且一鍵導出 SMT 生產檔！

💡 新手提示： 如果你對畫板不熟悉，可以直接拿此頁面的「引腳網路圖」與「BOM 清單」，在嘉立創 EDA 裡搜尋料號並拉線連接，完成後點選「檔案 ➔ 導出 ➔ 嘉立創生產檔 (Fabrication Files)」，系統會自動幫你打包好下單所需檔案。
2

準備好發包 JLCPCB 的三份核心檔案

要讓 JLCPCB 幫你焊元件，需要上傳以下三份檔案（EasyEDA 可一鍵全部導出）：

① Gerber 壓縮檔 (.zip)

洗電路板專用（包含走線銅皮、絲印、防焊層與鑽孔檔）。

② BOM 表 (.csv / .xlsx)

元件料表（記錄 R1、C1、U1 對應哪個 LCSC Part # Cxxxxxx）。

③ CPL / 座標檔 (.csv)

元件位置與旋轉角度（讓貼片機知道元件要焊在板子的哪個 X/Y 座標）。

3

在 JLCPCB 官網上傳並啟用 SMT 打件服務

打開 jlcpcb.com，點擊「Order Now / 立即下單」：

  1. 上傳 Gerber.zip，系統會自動解析板子尺寸（例如 45mm × 45mm 圓形板）。
  2. 在下方找到 「PCB Assembly (SMT)」 開關，將其打勾啟用。
  3. 選擇 Top Side (單面貼片)：強烈建議將 ESP32、電阻電容全部排在頂層，這樣只需支付一次 SMT 治具費！
  4. 組裝數量選擇 2片 或 5片（JLCPCB 經濟型打樣非常便宜）。
4

上傳 BOM 與 CPL 檔案並確認料件配對

點擊下一步後，系統會提示你上傳剛剛導出的 BOM.csv 與 CPL.csv：

⚠️ 省錢技巧：注意「基礎庫 (Basic Parts)」vs「擴展庫 (Extended Parts)」
• Basic Parts（基礎庫）：已經常駐在貼片機飛達上，換料費 $0 元！例如 0603/0805 電阻電容、常用三極管。
• Extended Parts（擴展庫）：工程師需要人工將料盤裝上機器，每種元件收取約 $3 USD 換料費。
👉 本頁提供的 BOM 表已針對 JLCPCB 優化，被動元件盡可能選用 Basic Parts，整批 5 片打樣含貼片成本約 $20 ~ $35 USD！
5

線上 DFM 3D 視覺校準（極關鍵！）

JLCPCB 會在網頁上生成 3D 虛擬打件預覽圖。請務必手動檢查：

  • Type-C 方向：Pin 腳有無對齊焊盤。
  • ESP32-S3 / WROOM 模組方向：確認天線部分朝向板邊外側，沒有旋轉 90° 或 180°。
  • 二極體 / IC 第 1 腳 (Pin 1 Dot)：確認極性圓點與 PCB 絲印圓點一致。

確認無誤後點擊送出付款，約 5~7 個工作天，焊接完畢的現成電路板就會宅配寄到你家！

📐 數學幾何嚴密推導（為什麼 Ø45mm 太擠？） 🧮

1. 圓形半徑與弦長公式：半徑 $R = 22.5\text{ mm}$。若兩顆模組緊貼並排在中心，總寬度 $W = 18 + 18 = 36\text{ mm}$（左右各半 $X = \pm 18\text{ mm}$）。

2. 邊緣允許的最大高度：$$Y_{max} = 2 \times \sqrt{R^2 - X^2} = 2 \times \sqrt{22.5^2 - 18^2} = 2 \times \sqrt{182.25} = 27.0\text{ mm}$$

3. 模組真實物理長度：ESP32 模組長度為 25.5 mm。

致命瓶頸： 雖然 $25.5\text{ mm} < 27.0\text{ mm}$，理論上只差 $1.5\text{ mm}$（上下各留 0.75mm）。但這完全沒算外圍焊接焊盤（Pads 需要外擴 1.2mm）！一旦加上 SMT 焊盤，四個角落會直接超出 PCB 圓形外弧，洗板時會被洗刀切斷焊盤！
💡 實際落地的 3 種最優工程解決方案 ✨
方案 1（最簡單／強烈推薦）：直徑改為 Ø48mm 或 Ø50mm
直徑只多 3~5mm，在車用出風口（一般直徑 65~75mm）上視覺完全無感！但這多出來的 3mm 讓 S3 與 WROOM 可以一上一下顛倒擺放，天線完全背對背拉開，Type-C 與螺絲柱完全放得下。
方案 2（極致小巧）：雙層夾心疊板 (Sandwich Puck) ➜ 可做 Ø40mm！
頂板放 GC9A01 圓屏 + 麥克風 + PTT 按鈕；底板放兩顆 ESP32 + 電源 + Type-C。兩片圓板透過 1.27mm 排針對插，直徑可以縮到超小 Ø40mm，厚度僅約 12mm！
方案 3（晶片選型瘦身）：改用 S3-MINI + PICO 晶片
若堅持單板 Ø45mm，將 S3-WROOM 改為 ESP32-S3-MINI-1（只有 16.6×13.2mm），藍牙換成 ESP32-PICO-V3-02（只有 7×7mm 的 SiP 封裝），面積縮小 60%，就能輕鬆放進 Ø45mm！
天線禁銅區 (Antenna Keep-out Zone) 📡

Car Puck 上有兩顆射頻模組（S3 WiFi 天線 + WROOM 藍牙天線）：

  • 兩顆天線必須朝向板邊邊緣：絕不能讓天線位於 PCB 正中央或被銅皮包圍。
  • 天線正下方嚴禁走線與鋪銅（Top/Bottom 全部挖空 Keep-out）：PCB 下方的所有層都要挖空，避免信號被地平面吸收造成車內斷線。
  • 兩顆天線彼此夾角或相距 >25mm：降低 WiFi 2.4GHz 與 Bluetooth 2.4GHz 的近場互擾。
車載電源突波防護 (Power & Transient) ⚡

車載供電（特別是點煙器轉換過程或引擎點火時）常伴隨高頻尖峰突波：

  • Type-C 輸入端放置 TVS 瞬態抑制二極體（如 USBLC6-2SC6 或 ESD9B5V），防止靜電打穿 S3 的 USB-CDC 通道。
  • 5V 輸入端並聯一個 100µF 貼片鉭電容或固態電容：吸收汽車發電機產生的低頻波動。
  • SY8089 走線原則：輸入電容、晶片 VIN/GND、電感、輸出電容迴路盡可能縮短且加寬銅箔（寬度 ≥ 1.0mm）。
高頻走線考量（I2S 數位音訊與 40MHz SPI） 〰️
SPI 螢幕線路 (GPIO 21, 47, 40, 41)

GC9A01 運作在 40MHz 高速 SPI。走線盡量在 Top 層直達螢幕 FPC 座，避免打過孔 (Via)。周圍盡量鋪地保護，長度不超過 50mm。

I2S 時脈與資料線路 (BCLK, LRCLK, DIN)

S3 至 WROOM 的三根 I2S 線必須伴隨地線走線，遠離天線與 DC-DC 電感開關節點（SW Pin），避免開關噪聲串入數位音訊。

底層完整鋪地 (Solid GND Plane)

建議採用 4 層板 (4-Layer: Signal / GND / Power / Signal)，JLCPCB 4 層板打樣價格已非常低廉（10x10cm 以內僅 $2 USD），底層有完整 GND 平面能徹底消除底噪。

❌ 絕對不要選：標準光敏樹脂 (SLA 9000R / 8000) 或 PLA ⚠️

初學者最常踩的大坑：為了追求便宜或表面光滑而選最便宜的白樹脂。

🔌 正下方 Type-C + Qi 雙電源自動切換電路 🔄

當同時支援「正下方 Type-C」與「Qi 無線供電」時，如何避免電源倒灌？

Power Path 自動路徑切換原理：

1. Type-C 插入時（優先權最高）：Type-C 的 5V 透過蕭特基二極體（如 SS34 / BAT54C）或 PMOS 理想二極體開關直接給板子供電，同時觸發 Qi 接收晶片的 EN/Disable 引腳，讓無線接收端進入高阻休眠，避免發熱。
2. Type-C 拔出時：系統瞬間無縫無感切換至底部的 Qi 無線線圈供電（5V 1A），維持 Marvin 不斷電重開。

🔬 微型晶片替代可行性評估 + 穿戴級微型 Qi 線圈指南 📐
1. S3-MINI-1 能完全取代 S3-WROOM 嗎？

答案：可以，但型號千萬不能買錯！
• 核心晶片同樣是雙核 LX7 240MHz，指令集與引腳映射 100% 相同。
• ⚠️ 致命型號陷阱：目前韌體解碼與頭部動畫需要 8MB PSRAM。在選購 S3-MINI-1 時，必須指定選用 ESP32-S3-MINI-1-N8R8（8MB Flash + 8MB Octal PSRAM）。若買到 N4R2（只有 2MB Quad PSRAM），會因記憶體不足報 OOM 錯誤！只要選對 N8R8，程式碼完全零修改直接跑。

2. 藍牙端能用 PICO-V3-02 取代 WROOM 嗎？

答案：完全相容，而且體積從 25.5×18mm 暴降到 7×7mm！
• ESP32-PICO-V3-02 內部就是原版雙核 ESP32-D0WD-V3 + 8MB Flash，Classic BT A2DP Source 與 AVRCP 韌體 100% 相同。
• ⚠️ 注意天線設計：PICO 是 7×7mm QFN 裸晶封裝，不帶板載天線。需要在 PCB 邊緣加上一個微型 陶瓷貼片天線 (Chip Antenna, 3.2×1.6mm)，JLCPCB 可直接貼片！

3. Qi 充電線圈可以做多小？

答案：可以從常規 Ø40mm 縮小到 Ø25mm~Ø28mm！
• 車載手機充電盤是 15W 大功率，才需要 Ø40mm 大線圈。
• Marvin Puck 雙晶片功耗僅約 2.5W (5V 0.5A)，完全可以使用穿戴式裝置/藍牙耳機盒專用的微型 Qi 線圈（Ø25mm~Ø28mm，厚 0.6mm）。
• 縮小後的線圈只佔據底盤中心，外圍留給 MagSafe 磁吸環（Ø54mm），外觀尺寸可以極度精緻！
