## 零、v1 → v2 改了什麼

| # | v1 | v2 | 理由 |
|---|---|---|---|
| 1 | `ESP32-S3-MINI-1-N8R8` | **`ESP32-S3-MINI-1-N4R2`**（4MB flash / 2MB Quad PSRAM，**15.4×20.5×2.4**） | N8R8 不存在；MINI-1 只有 `-N8`（無 PSRAM）與 `-N4R2`。N4R2 額定 85°C，PCB 天線已認證 |
| 2 | 裸晶 `ESP32-PICO-V3-02` ＋自畫陶瓷天線 | **`ESP32-MINI-1-N4`** 模組（ESP32-U4WDH 雙核 240MHz，Classic BT，13.2×19.0×2.4，85°C；`-H4` 為 105°C 版） | 免自己做 RF 匹配。原本選的 PICO-MINI-02 datasheet v1.8 已標 **NRND**，不用 |
| 3 | 雙層夾心板＋12-Pin 排針 | **單片 Ø38.4mm 4 層板，雙面貼** | 排針只有 1 根 GND、4.5mm 板間距吃掉厚度；兩顆模組並排放得進 Ø38.4（已驗算四角） |
| 4 | Apple Watch 磁吸無線充 | **背面 2P 磁吸 pogo（5V/GND）＋自製出風口座** | Apple Watch 充電是專屬協定，一般接收線圈從它取不到電；引鐵片在磁場裡會發熱 |
| 5 | 總厚 14mm（實際疊不下） | **目標約 10mm**（見 §四 疊層表） | 少一片板＋少排針 |
| 6 | PTT 在板子背面（按不到） | **側面按鍵，9 點鐘** | — |
| 7 | 沒有 PICO 燒錄口、沒有配對鍵 | **BT 模組測試點＋背面配對針孔（附 LED）** | 配對新車要長按 GPIO0 |
| 8 | 麥克風孔在螢幕窗內 | **側壁 Ø0.8 孔，8 點鐘；改用上收音麥克風 MSM261S4030H0R 貼正面，Poron 聲道通到側壁** | 前蓋外圈只剩約 1mm 寬，開不了孔；INMP441 庫存稀少、ICS-43434 TDK 已標 EOL |
| 9 | 外殼壁厚 1.2 | **1.5** | JLC3DP 指南：50mm 級零件、卡扣結構壁厚建議 ≥1.5 |

## 一、待使用者拍板（影響後面全部）

| 決策 | 建議 | 另一選項 | 取捨 |
|---|---|---|---|
| **D1 S3 模組** | **MINI-1-N4R2** | ESP32-S3-PICO-1-N8R8（7×7 SiP） | N4R2：認證天線，但 PSRAM 2MB Quad → 韌體 ring 要縮、頭像幀率要過 G1。PICO-1-N8R8：8MB 韌體零改，官方標 65°C（puck 不留在車上、行駛有冷氣，溫度不再是否決理由），但要自己畫天線匹配 |
| **D2 磁吸供電** | **2P 磁吸 pogo＋自製座** | 只留 Type-C | pogo 要多設計一個出風口座；只留 Type-C 最簡單，但要插線 |
| **D3 S3 的 RGB 狀態燈（GPIO48）** | **拿掉** | 保留＋導光柱 | 有螢幕之後狀態燈重複；黑色 PA12 裡面看不到。韌體 `neopixelWrite` 打到空腳無害，不用改 |
| **D4 PTT 位置** | **9 點鐘側面**（puck 在中控出風口時朝駕駛） | 3 點鐘／整個前蓋當按鍵 | 前蓋按壓要做浮動機構，厚度會增加 |
| **D5 AUX 輸出** | **不做**（只走藍牙） | 加 PCM5102＋3.5mm | 現有 car_puck 有 PCM5102 給 AUX 車用；Ø42 塞不下 3.5mm 座。有 AUX 的車繼續用現有 dev 板版本 |
| **D6 BT 模組韌體更新** | **第一版：正面測試點，更新要拆殼** | S3 轉燒（S3 兩根 GPIO 接 BT EN/IO0，UART 改接 BT UART0） | bt_bridge 改版頻率高，拆殼很煩；但 S3 轉燒要動兩邊韌體與 UART 配置，等第一版跑穩再做 |

以下內容依「建議」那欄寫。改選另一欄時，對應段落要重寫。

## 二、單板架構

```
 前蓋（PA12，外圈唇邊 0.8mm 蓋住螢幕邊）
   │ 螢幕 GC9A01 1.28"（玻璃約 Ø35.6，待量實物）
   │ 泡棉膠 0.3
 ┌─┴───────────────── PCB 正面（朝螢幕）：只放 ≤1.0mm 高的件 ─────────┐
 │ FPC 座、SY8089＋電感(≤1.0mm)、去耦、背光 MOSFET、ESD、EN RC、測試點、│
 │ 麥克風（上收音，1.0mm）＋Poron 聲道                                  │
 ├──────────────────── Ø38.4mm 4 層板 1.0mm ─────────────────────────┤
 │ PCB 背面（朝底蓋）：S3-MINI-1、ESP32-MINI-1、Type-C(板邊貼片)、      │
 │ 配對鍵＋LED、PTT 側按鍵、二極體、bulk 電容、pogo 焊點               │
 └─┬─────────────────────────────────────────────────────────────────┘
   │ 底蓋（PA12）：2P 磁吸 pogo 母座 ＋ 2 顆 Ø6×1.5 釹磁鐵
```

### 2.1 擺位（座標從正面透視：12 點鐘 +y、3 點鐘 +x，單位 mm，板 r=19.2）

- **兩顆模組並排在上半部，天線端都朝 12 點鐘**：S3（15.4×20.5）在左 x −14.6 ~ +0.8、y −8.15 ~ +12.35；ESP32-MINI-1（13.2×19.0）在右 x +1.4 ~ +14.6、y −6.65 ~ +12.35。外側角離圓心 19.12，放得下（2026-10-25 程式驗算）。
  - 天線區：S3 是模組頂端 5.05mm、ESP32-MINI-1 約 5.5mm（datasheet 封裝圖）。**天線區加上它到板緣之間的弓形區，所有層禁銅、禁走線**；兩塊禁銅區之間留 ≥0.6mm。
  - 模組外側角可以伸出板緣（Espressif 本來就建議天線區伸出底板），最多 0.3mm 到外殼內壁。
  - 垂直擺放（一顆天線朝 12、一顆朝 9）塞不下，已算過，不要再試。
- **背面下半部**：pogo 焊點 (±2.5, −11.0)、D1 (−7.5, −11) / C1 (−7.5, −13.8)、D2 (7.5, −8.5) / C2 (7.5, −11.2)、配對鍵 SW2 (13.3, −8.0)＋LED2 (13.3, −10.0)。
- **6 點鐘**：Type-C **TYPE-C-31-M-12（LCSC C165948）一般上貼式 16P，貼在背面**（v1 說它是中沉座，查 LCSC 是右彎上貼式）。本體 8.94×7.35、高約 3.2。前緣伸出板緣約 1.2mm，插座面離外殼外表面約 0.6mm。背面因此最高 3.3mm。
- **9 點鐘板緣**：PTT 側按鍵 SW1 (x −19.0 ~ −15.5)。
- **磁鐵**（底蓋 (±9.2, −9.2)）頂面在 z=1.9，背面零件最低到 z=2.5（模組）／3.9（小零件），**只有 Type-C 不能疊在磁鐵上**。
- **正面（朝螢幕，≤1.0mm）**：SY8089＋L1＋回授電阻（3 點鐘附近）、FPC 座 J2（6 點鐘，r≈13）、背光 Q1、USB ESD、EN RC、BT 模組測試點 2×3（2.54mm）、**麥克風 MIC1 (−11.8, −11.2)** 與 Poron 聲道（往 8 點鐘側壁，約 5mm）。

### 2.2 兩顆無線晶片的隔離

兩顆是獨立晶片，沒有硬體 coexistence 仲裁，天線又同朝 12 點鐘、中心距約 14.5mm。現在 dev 板版本在車上也是兩塊板靠很近，沒出過問題。不過 v2 更近，所以 **G2 實測**是驗收必過項。

## 五、電源

```
Type-C VBUS ──D1──┐
                  ├── VSYS ──[2×100µF]── SY8089 ── 3V3（2A）
pogo 5V ─────D2──┘
```

- **SY8089 是可調版**（FB 0.6V），要回授分壓：R_FB1 100k（上）／R_FB2 22.1k（下）→ 0.6×(1+100/22.1) ≈ 3.31V。EN 直接接 VIN。
- **D1/D2**：SOD-123FL 低 Vf 蕭特基（≥1A，例如 SS14/B5819W 級）。SMA 封裝太大，不用。二極體讓 pogo 焊點在沒上座時**不帶電**，puck 背面碰到金屬也不會短路。
- **無縫切換**：插著 Type-C 時 pogo 也通著，兩邊同時供電；拔掉任一邊，另一邊本來就在供。bulk 電容負責吸收 WiFi 發射的瞬間電流。不保證「Type-C 優先」，也不需要。
- **功耗預估**：S3 WiFi 發射峰值約 355mA（datasheet 802.11b 20.5dBm）、ESP32 BT 約 130mA、背光約 40mA，3V3 峰值約 0.55A；5V 端平均約 0.45A。SY8089 2A 夠。
- **Type-C**：16P、CC1/CC2 各 5.1k 下拉、D+/D− 經 USBLC6-2SC6。
- **磁吸 pogo**：買現成的「2P 磁吸 pogo 公母座」（自帶對位磁鐵，額定 ≥1A）。參考：EDAC 685 系列 5V 2A 版約 Ø8.3×6.5（685C02212021C1E）；淘寶通用款要自己量。母座（平面接點）在 puck，公座（彈針）在出風口座＋USB-C 線。

## 八、韌體改動（D1 選 N4R2 時）

| 檔案 | 改動 | 原因 |
|---|---|---|
| `car_puck.ino:388` | `STREAM_RING_SIZE` 1MiB → **256KiB** | 2MB PSRAM。128kbps MP3 下 256KiB ≈ 16 秒緩衝（原本約 64 秒），熱點斷線抗性下降，G1 要量 |
| FQBN | `PSRAM=opi` → `PSRAM=enabled`；`FlashSize=16M` → `4M`；`PartitionScheme` → `min_spiffs`（1.9MB app＋OTA）或 `huge_app`（3MB） | 正式版 bin 約 1.4MB，兩種都放得下；10/25 那份 2.78MB 的 build 只放得進 `huge_app` |
| `car_puck.ino:2387-2388` | PSRAM 檢查門檻 4MB → 2MB、訊息改字 | 只是 log，不改不會壞，但會誤報 ❌ |
| `bt_bridge.ino:958` | UART2 腳 16/17 → **32/33**（已確認必改） | ESP32-U4WDH 的 16/17 接內建 flash |

**PSRAM 實測（2026-10-25 17:24–17:32，N16R8 正式韌體＋播歌＋封面＋Funnel 下載底圖）**：開機以來最低剩餘 `pmin=6,085,528` → 峰值用量約 **2,303,080 B**（ring 1MiB）。v2 ring 縮成 256KiB 後約 **1.45MiB**，2MB 剩約 0.55MiB（約 27%）。**容量夠，不用買板子驗。**

**PSRAM 預算（手算，跟實測吻合；N4R2，FACE_DISPLAY=1、FACE_BENCH=0）**：錄音 320,000＋頭像 base/out 2×172,800＋底圖 skinBuf/skinShow 2×172,800＋封面 2×65,536＋ring 262,144＋faceWork/faceTask stack 約 15K ≈ **1.42MB / 2MB**，剩約 0.6MB 給 WiFi/LWIP 的大塊配置。
